## 实测结论

- 在当前 8 道来源题 + 混合检索设定下，**400 / 800 / 1200 / 1600 的 Recall@1、@3 打平**。
- 切片变短：块数增加（400 → 42 块）；变长：单块更完整、块数减少。
- **保留生产默认 `max_chars=1200 / overlap=120`**：与现有入库、API、评测一致，无证据表明需改。
- 口径限制：关键词出现在 Top-k 即算命中，**偏松**；切片越碎关键词越容易“碰到”，不能外推「切片长度对生成质量不重要」。语料扩大后需重跑本消融。
